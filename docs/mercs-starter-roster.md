# Starter Mercenaries: Max-Power Reference

These are the 8 mercs Hearthstone gave new players for free. Everything is at max power: **level-30 stats, tier-5 abilities and tier-4 equipment**. Since your version has no leveling, these are the numbers to use. The same data is in `mercs-starter-roster.json`, ready to load.

Conventions: **Spd** = speed, and lower acts first. **CD** = cooldown in turns ("—" means none). School "—" means no spell school. Each merc can equip **one** of its three items.

## At a glance

| Merc | Role | Faction / Type | ATK / HP | Plays like |
|---|---|---|---|---|
| Cariel Roame | Protector | Alliance / Human | 11 / 73 | Self-sustaining tank and buffer |
| Cornelius Roame | Protector | Alliance / Human | 12 / 79 | Heals adjacent allies, redirects damage to himself |
| Grommash Hellscream | Protector | Horde / Orc | 12 / 74 | Offensive tank: slows enemies, snowballs Horde on kills |
| Tyrande Whisperwind | Fighter | Alliance / Night Elf | 7 / 81 | Arcane ranged damage, speed manipulation |
| Blademaster Samuro | Fighter | Horde / Orc | 10 / 66 | AoE, summons, double hits |
| Rokara | Fighter | Horde / Orc | 9 / 74 | Orc synergy, team Attack buff |
| Xyrella | Caster | Alliance / Draenei | 5 / 68 | Healer whose finisher grows with healing |
| Millhouse Manastorm | Caster | — / Gnome | 5 / 69 | Arcane AoE and scaling spell damage |

Two synergy packages come out of these eight: **Orc/Horde** (Grommash, Samuro, Rokara) and **Alliance** (Cariel, Cornelius, Tyrande, Xyrella). Casters are thin, with only two. If you want more caster options, that's the obvious next batch to research.

## What these abilities need from the engine
Building these 8 mercs covers most of the effect primitives the full game uses:

| Primitive | Used by |
|---|---|
| Attack (with counter-damage) | Crusader's Blow, Martial Mastery, Blood Fervor, Tribal Warfare, Double Strike |
| Attack an enemy + a neighbour (cleave) | Battlefury |
| Attack twice / conditional re-attack | Double Strike ("damaged this turn" needs a per-turn damage log) |
| Deal N to one / all / N random enemies | Arcane Shot, Arcane Explosion, Whirling Blade, Arcane Salvo, Greater Arcane Missiles |
| Repeat-while condition | Arcane Salvo ("if any die, repeat"), Orc Onslaught ("repeat per Orc") |
| Heal self / target / adjacent | Taunt, Seal of Light, Flash Heal, Hold the Front |
| Permanent stat buff (+ATK, +max HP) | Seal of Light, Martial Mastery, Battlefury, Blood Fervor, Burning Blade |
| "This turn" stat debuff | Blinding Luminance |
| Timed status (Taunt N turns, Immune this turn) | Taunt, Hold the Front, Whirling Blade |
| Speed modifiers (next ability / permanent) | Staggering Slam, Elune's Grace |
| Deathblow trigger | Crusader's Blow, Blood Fervor |
| "Whenever X this turn" listener | Offensive Rally, Blessing of Sacrifice (damage redirect) |
| Summon a temporary copy | Mirror Image (a minion with this merc's stats, dies at end of turn) |
| Next-ability modifier (cast twice) | Elune's Grace |
| Growing counter ability | Atonement (tracks healing done by your team), Arcane Bolt (stacking +Arcane Damage) |
| Synergy checks by faction / type / role / "has acted" | Blood Fervor, Tribal Warfare, Orc Onslaught, Martial Mastery, Elune's Charm |
| Flat damage reduction | Shield of Dawn |
| Item that changes an ability's cooldown | Shard of the Naaru, Mana Rod |

### Ambiguities to settle before coding
- **Flash Heal and Arcane Bolt don't say "to an enemy" or "to a friendly".** They're single-target: the card targets a friendly character and an enemy respectively.
- **Atonement:** in the real game "you" means healing done by *your whole team* during the fight. A good implementation stores a team-wide healing counter and computes the bonus as `floor(totalHealed / threshold) × perStep`.
- **Offensive Rally at speed 2:** only Attacks that resolve *after* it get the buff. Offensive Rally plus a speed-6 attacker is the intended combo.
- **Mirror Image:** the copy is a minion, so it has no role and gets no role crit, and it's a legitimate target that soaks random hits until it dies at end of turn.
- **Staggering Slam vs Elune's Grace:** both change speed. Apply speed mods to the queued ability and re-sort the rest of the queue (see the mechanics spec §5).
