Theomachy

Blind orders. Resolved by speed, lowest first.

How it works. Both sides commit every order before either sees the other's. Everything then resolves from the lowest speed to the highest, so a fast kill denies a slow ability outright — the victim dies before acting, and any single-target ability aimed at the dead fizzles. Protector beats Fighter beats Caster beats Protector, at double damage. Ability cooldowns start spent, so round one is the narrowest round of the fight.
