# Portrait art

One image per merc, named by its id. Any of `.png`, `.jpg`, `.webp` or `.avif` works.

The pixel portraits for the original roster (`brannoc`, `rurik`, `gorsebark`,
`vessa`, `nyxa`, `torvik`, `lyra`, `grisk`, `aurelle`, `oona`, `mordekai`, `ilsa`,
plus the `wolf` and `skeleton` summons) are generated by
`node scripts/pixel-portraits.mjs`. Overwrite any of them with your own art.
Re-running the script overwrites them again, so delete that character from the
script first if you've replaced it.

The classic roster (`cariel`, `cornelius`, `grommash`, `tyrande`, `samuro`,
`rokara`, `xyrella`, `millhouse`) has no files and shows a coloured placeholder
until you add some.

Portraits are cropped to an oval about 4:5, so keep the face centred with some
headroom.
