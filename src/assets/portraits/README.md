# Portrait art

Put one image per merc here, named by its id:

`cariel`, `cornelius`, `grommash`, `tyrande`, `samuro`, `rokara`, `xyrella`, `millhouse`

Any of `.png`, `.jpg`, `.webp` or `.avif` works. The UI picks them up at build
time and uses them instead of the coloured placeholder. Portraits are cropped
to an oval, so keep the face centred with some headroom. 512x640 or larger
works well.
