# Portrait art

One image per merc, named by its id. `.svg`, `.png`, `.jpg`, `.webp` and `.avif`
all work; an SVG wins if two files share a name. PNGs are drawn with hard pixel
edges, so they suit pixel art.

The original roster uses flat, Reigns-like SVG portraits on a 400x500 canvas:
`brannoc`, `rurik`, `torvik`, `aurelle` (Ironvow, rust), `gorsebark`, `lyra`,
`grisk`, `oona` (Thornwild, moss), `vessa`, `nyxa`, `mordekai`, `ilsa` (Hollow
Court, slate), plus the `wolf` and `skeleton` summons.

The style, if you add more:

- Flat fills only. Each shape gets one darker plane on the side away from the
  light (light comes from the left), split slightly off-centre.
- No outlines, gradients or glow. Keep the paper-grain filter layer on top.
- Four to six muted colours, plus one accent that belongs to the character.
- Small, still faces. The brows, the eyes and one signature feature carry them.
- Background in the faction hue, with a slightly lighter circle behind the head.

The classic roster (`cariel`, `cornelius`, `grommash`, `tyrande`, `samuro`,
`rokara`, `xyrella`, `millhouse`) has no files and shows a coloured placeholder.

Earlier pixel-art versions of the originals are in `docs/portrait-styles/pixel/`,
generated by `node scripts/pixel-portraits.mjs`.
